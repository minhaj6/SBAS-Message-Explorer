SBAS Message Explorer

Open an EMS or GNSS-SDR .ems file and inspect every SBAS L1 frame bit by bit, decoded per RTCA DO-229 Appendix A. Files are read in your browser and never uploaded.

Layouts follow RTCA DO-229 Appendix A; IGP band geometry follows RTKLIB. Message slots and grid points are resolved through the PRN mask (MT1) and IGP mask (MT18) found anywhere in the loaded file with the matching issue of data, so a message received before its mask is still explained. Line format explanations are inspired by the gAGE file format explorers.
